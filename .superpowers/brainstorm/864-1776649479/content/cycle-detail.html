Decisões embutidas:
• /avaliacoes: listagem simples. Seção destacada "Pendentes para você" no topo (assignments do próprio user) + lista de todos os ciclos da empresa. Click → /avaliacoes/[cycleId].
• Filtros em /avaliacoes: busca + status (rascunho/agendado/em andamento/encerrado/arquivado).
• /avaliacoes/[cycleId]: header com metadados, 4 KPI cards (participantes, assignments, progresso %, atrasadas), 4 tabs (Progresso · Participantes · Formulário · Resultados).
• Tab Progresso: tabela de participantes × self/gestor, status visual (✓ / ● / ○). Kebab por linha: reenviar lembrete individual, ver detalhes, cancelar assignment, reatribuir reviewer.
• Tab Participantes: gerenciar quem está no ciclo (adicionar/remover pós-publish).
• Tab Formulário: read-only após publicar (só admin_rh pode ver as perguntas).
• Tab Resultados: disabled enquanto ciclo não está closed. Quando closed, mostra resumo + link pro resultado individual de cada colaborador.
• Botões de ação: "Reenviar lembretes" (envia e-mail via Resend para todos com assignments pending/in_progress), "Encerrar ciclo" (status = closed, modal de confirmação "Isso impedirá novos envios. Confirma?").
• "Pendentes para você" aparece também no Dashboard stub (FT-5 já lança).
• Rascunhos: linha em cinza, sem progresso; clicar leva para o wizard no passo correspondente.
