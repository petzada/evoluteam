Decisões embutidas (valem para Departamentos E Cargos):
• Criar: botão "+ Novo" abre modal pequeno com um campo "Nome". Validação: UNIQUE(company_id, name) (já no schema Fase 0).
• Editar nome: click no nome → modal com input pré-preenchido. Zod valida tamanho.
• Arquivar (soft delete): is_archived = true. Departamento some dos selects novos, mas mantém vínculo nos employees existentes (employees.department_id continua apontando para ele — aparece no perfil como "Operações (arquivado)").
• Desarquivar: is_archived = false. Volta a aparecer em selects.
• Deletar permanentemente: disponível só se 0 colaboradores vinculados (ativo OU arquivado). Caso contrário, item "Deletar" no kebab fica disabled com tooltip "Remova os colaboradores vinculados antes".
• Contagem "N colaboradores": conta employees ativos+inativos (não conta desligados). Link clicável → abre /colaboradores?department=X.
• Arquivados ocultos por default, toggle "Mostrar arquivados" no topo.
• Kebab (⋯): Editar, Arquivar/Desarquivar, Deletar (se possível).
• /configuracoes/cargos é IDÊNTICO em estrutura — só muda copy e tabela subjacente (positions).
