Decisões embutidas:
• Modal centralizado (480px), não side sheet. Ação focada, desloca atenção do que está embaixo.
• Destinatário — autocomplete de employees ativos/inativos (exclui desligados e self).
• Pré-seleção: quando aberto de /colaboradores/[id] ou deep link com query param, destinatário vem pré-preenchido.
• Tipo como 5 cards selecionáveis (grid 2×2 + 1 full-width pra privada). Mais visual que dropdown.
• "Observação privada" quando selecionado: força visibilidade "privado" + desabilita radios (ou esconde bloco de visibilidade).
• Competência opcional; default "Nenhuma".
• Mensagem obrigatória, min 20 / max 2000 chars (soft limit). Contador inline.
• Visibilidade radio-card com 3 opções, default "Privado" (mais conservador).
• Envio: cria row em feedbacks, dispara notify(destinatário, type='feedback_received'), logActivity('feedback.sent'), toast de sucesso, modal fecha.
• Sem edição após envio: feedback é imutável. Admin_rh pode deletar (hard delete) com log; autor não tem edit nem undelete.
• Sem anexos: MVP 1.0 só texto.
