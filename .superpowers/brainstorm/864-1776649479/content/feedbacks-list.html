Decisões embutidas:
• 3 abas: Recebidos (default para qualquer user) / Enviados / Minha equipe (visível só para quem é gestor — mostra feedbacks recebidos pelos liderados diretos/indiretos, respeitando visibilidade).
• Badge "N novos" em Recebidos quando há feedbacks com read_at IS NULL.
• Filtros: Tipo, Competência, Período (últimos 30 dias / 6 meses / 1 ano / customizado).
• 5 tipos com cor/ícone próprios:
  👏 Elogio (verde) · 🎯 Reconhecimento (azul) · 🔄 Ponto de melhoria (amarelo) · 🧭 Orientação (cinza) · 🔒 Observação privada (cinza escuro)
• 3 visibilidades com ícone próprio:
  🔒 Privado (só emissor + destinatário) · 👥 Visível para gestor (emissor + destinatário + gestor direto do destinatário) · 🏢 Visível para RH (emissor + destinatário + todos os admin_rh)
• Observação privada = tipo especial com visibilidade forçada privado. Serve para "nota pessoal", ninguém além dos dois vê.
• Card do feedback: avatar do emissor + nome + data + pills (tipo + competência + visibilidade). Mensagem abaixo.
• Sem reações, sem comentários: MVP 1.0 mantém simples.
• Listagem paginada — 20 por página. Ordem: mais recente primeiro.
• Aba "Minha equipe" só aparece se o user é gestor de alguém (derivado via manager_id).
