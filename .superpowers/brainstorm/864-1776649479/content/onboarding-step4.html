O que acontece ao clicar "Criar minha empresa":
1. Server Action createCompany() é chamada
2. Transação única insere: companies (1 row), employees do admin (1 row), positions (4 seed rows), competencies (7 seed rows), departments (0 ou 1 row)
3. profiles.role do admin = admin_rh
4. employees.user_id do admin aponta pro auth.users.id
5. activity_logs registra company.created
6. Redireciona para /dashboard com toast "Empresa criada com sucesso"
7. Se qualquer passo falhar → rollback completo + mensagem de erro no wizard
