Decisões embutidas:
• Layout 2 colunas: sidebar esquerda (resumo) + detalhe à direita.
• Sidebar: Média geral (cartão laranja, destaque) + Top 3 competências (pontos fortes verde) + Bottom 2-3 (pontos a desenvolver amarelo) + CTA "Criar PDI com base neste resultado" (linka para FT-4 quando existir).
• Pontos fortes/desenvolver auto-gerados: top 3 / bottom 2-3 das médias por competência. Se houver empate, ordenação estável por nome da competência.
• Detalhe à direita: tabela self × gestor × delta (Δ) + lista de comentários de texto agrupados por pergunta com rótulo do autor.
• Delta colorido: +N verde, -N vermelho, 0 cinza. Ajuda a detectar divergência de percepção.
• Comentários: texto integral. Sem anonimato (MVP não tem). Agrupa por pergunta; mostra quem respondeu ("autoavaliação" ou "gestor (nome)").
• Banner "🔒 Oculto do colaborador" + botão "Liberar resultado" (só admin_rh). Liberado → banner vira "✓ Liberado em DD/MM" e botão some.
• Exportar PDF disabled com "Em breve" no MVP 1.0 (ou remover o botão — decidir abaixo).
• Cálculo: média simples por competência (só perguntas de nota); média geral = média das médias por competência (ou média simples de TODAS as perguntas — ver decisão abaixo). Assignments cancelled são ignorados; só submitted entra no cálculo.
• Cálculo on-the-fly: sem tabela review_results no MVP. Queries computam via views/SQL agregado. Simples, consistente.
• Release flag: review_cycle_participants.result_released_at + result_released_by.
• Colaborador vê: só se released_at != NULL. Caso contrário, página dele mostra "Resultado ainda não liberado. Fale com seu RH."
