Decisões embutidas:
• Lista unificada de usuários ativos + convites pendentes/expirados (não separo em abas — é a mesma operação gerencial).
• Colunas: Nome+email, Cargo, Papel (pill colorida), Status (ativo/pendente/expirado), ações (kebab menu).
• Filtros: busca livre + status + papel.
• Ações do kebab (⋯): editar papel, reenviar convite (se pendente/expirado), revogar convite, desativar user (se ativo).
• Coluna "Departamento" intencionalmente omitida para caber tudo; aparece no perfil detalhado em FT-1.
• Linha do próprio admin vem com tag "(você)" e ações restritas (não pode se auto-desativar).
• Paginação: 20 por página (padrão TanStack Table), aparece quando >20 rows.
