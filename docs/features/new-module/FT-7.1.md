1. Vagas

Antes de cadastrar candidatos soltos, o RH precisa cadastrar uma vaga.

Users should be able to

Users should be able to criar uma vaga de emprego.

Users should be able to editar uma vaga.

Users should be able to arquivar uma vaga.

Users should be able to definir título da vaga.

Users should be able to definir departamento da vaga.

Users should be able to definir gestor responsável pela vaga.

Users should be able to definir quantidade de posições abertas.

Users should be able to definir tipo de vaga, como CLT, PJ, estágio, temporário ou freelancer.

Users should be able to definir modalidade, como presencial, remoto ou híbrido.

Users should be able to definir localidade da vaga.

Users should be able to definir status da vaga, como aberta, pausada, fechada ou cancelada.

Users should be able to visualizar todas as vagas da empresa.

Users should be able to filtrar vagas por status, departamento e responsável.
