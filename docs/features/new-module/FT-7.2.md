2. Candidatos

O candidato é parecido com um colaborador, mas ainda não pertence oficialmente ao quadro da empresa.

Users should be able to

Users should be able to cadastrar candidato manualmente.

Users should be able to editar dados do candidato.

Users should be able to vincular candidato a uma vaga.

Users should be able to listar candidatos por vaga.

Users should be able to buscar candidato por nome, e-mail ou telefone.

Users should be able to adicionar origem do candidato.

Users should be able to adicionar observações internas sobre o candidato.

Users should be able to marcar candidato como desistente.

Users should be able to marcar candidato como reprovado.

Users should be able to marcar candidato como contratado.

Users should be able to converter candidato contratado em colaborador.
