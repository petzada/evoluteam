4. Feedbacks e avaliações do candidato

Aqui você conecta o módulo novo com o conceito que seu produto já tem: feedback.

Só que agora o feedback é sobre candidato, não colaborador.

Users should be able to

Users should be able to registrar feedback sobre um candidato.

Users should be able to registrar feedback vinculado a uma etapa do funil.

Users should be able to dar uma nota para o candidato em uma etapa.

Users should be able to criar scorecard simples de entrevista.

Users should be able to visualizar feedbacks anteriores do candidato.

Users should be able to ver quem avaliou o candidato.

Users should be able to comparar avaliações de RH e gestor.
