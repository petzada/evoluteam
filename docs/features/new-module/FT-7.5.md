5. Métricas do funil

Esse é o motivo principal da feature.

O RH quer responder:

quantos candidatos entraram?
quantos avançaram?
onde estão desistindo?
onde estão sendo reprovados?
quanto tempo demora para contratar?
qual origem traz melhores candidatos?

A Gupy também destaca visibilidade de indicadores em todas as etapas do processo seletivo como parte da plataforma de Recrutamento e Seleção.

Users should be able to

Users should be able to visualizar quantidade de candidatos por etapa.

Users should be able to visualizar taxa de conversão entre etapas.

Users should be able to visualizar taxa de desistência por etapa.

Users should be able to visualizar taxa de reprovação por etapa.

Users should be able to visualizar tempo médio em cada etapa.

Users should be able to visualizar tempo total médio até contratação.

Users should be able to visualizar origem dos candidatos.

Users should be able to visualizar origem dos candidatos contratados.

Users should be able to visualizar candidatos parados por muitos dias.

Users should be able to filtrar métricas por vaga.

Users should be able to filtrar métricas por período.

Users should be able to filtrar métricas por responsável.
