6. Tarefas e próximos passos

Para não virar bagunça, cada candidato precisa ter um próximo passo.

Users should be able to

Users should be able to criar tarefa vinculada a um candidato.

Users should be able to definir responsável pela tarefa.

Users should be able to definir prazo da tarefa.

Users should be able to marcar tarefa como concluída.

Users should be able to visualizar tarefas pendentes por vaga.

Users should be able to visualizar tarefas atrasadas.

Exemplos:

Agendar entrevista
Enviar teste técnico
Cobrar retorno do gestor
Enviar proposta
Dar feedback negativo

Essa feature parece simples, mas ajuda muito o RH no operacional.
