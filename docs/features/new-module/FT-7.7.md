7. Conversão de candidato em colaborador

Essa é a ponte perfeita com seu MVP atual.

Quando alguém for contratado, você não quer cadastrar tudo de novo.

Users should be able to

Users should be able to marcar candidato como contratado.

Users should be able to converter candidato contratado em colaborador.

Users should be able to pré-preencher colaborador com dados do candidato.

Users should be able to definir cargo, departamento e gestor do novo colaborador.

Users should be able to manter histórico do processo seletivo após contratação.

Isso é muito bom para o produto, porque o ciclo fica completo:

Candidato → Contratado → Colaborador → Avaliação → Feedback → PDI
